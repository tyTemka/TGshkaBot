Данный бот создан для ведения заметок в телеграме

## Основные функции:
1) Обычные заметки
2) Оповещения, по времени со следующими свойствами:
  2.1) по определённым дням
  2.2) по определённому времени
  2.3) через определённый промежуток времени
  2.4) повторные оповещения(через каждые 5 минут)
3) Реализовать группы заметок/оповещений
4) Отключение всех оповещений выбранной группы

## Список задач

Задача 1: 
Цель: Сделать заготовку чат-бота для Telegram, которая умеет отвечать на несколько команд:
- /about — выводит краткую информацию про бота
- /authors — выводит информацию об авторах
- /help — выводит информацию обо всех доступных командах (можно запускать с аргументом: /help <command>.

Задача 2: Подключение базы данных
Цель: Реализовать команды:
- добавления (/addNote)
- удаления (/removeNote)
- просмотра заметок (/showNote)
- редактирования заметок (/editNote)

Задача 3: Оповещения и кнопки inline
Цель: Реализовать напоминание заметок по времени + добавление кнопок быстрого доступа на часть команд:
- кнопка на команду помощи(/help)
- кнопка на команду добавления заметки (/addNote)
- кнопка на команду просмотра заметок (/showNote)
- кнопка на команду удаления заметки (/removeNote)

Задача 4: Реализовать возможность делиться заметкой с другими пользователями.
Цель: Заметка будет передаваться другому пользователю копированием оригинала, пользователь будет получать ссылку и, переходя по ней, у него будет добавляться заметка список своих

_Как будет работать команда:_
- вызывается команда (/share)
- выбираем какую заметку хотим переслать 
- формируется id заметки, например "note_171234567890"
- сформируем ссылку httрs://t.me/Бот?share_note_171234567890
- пользователь Б переходит по ссылке, бот ищет в Мар по ключу(id заметки), находит данные и сохраняет их копию у получателя
